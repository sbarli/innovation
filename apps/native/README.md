# Native

A [react-native](https://reactnative.dev/) app built using [expo](https://docs.expo.dev/)

## UX Pilot

### Prompt

```
For an iPad
Create a board game app screen with the following layout:

- Up to four player’s boards: each player board consists of 5 card piles
- Current player’s hand
- Deck: 10 card piles
- Achievements: 9 individual cards
- Special Achievements: 5 individual cards
- A section to show the current game status: current player’s score, number of achievements, possible actions, and number of cards in hand
```
